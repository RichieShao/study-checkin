# 小学生学习打卡应用设计文档

## 1. 项目背景

用户的孩子刚刚六年级毕业，开学需要参加分班考试。需要一个网页版应用来帮助孩子每天安排学习打卡任务，并支持家长查看学习情况。

## 2. 目标用户

- **小孩**：刚小学毕业，需要简单直观的界面来添加和完成每日学习任务
- **家长**：需要查看孩子的打卡统计、历史记录和整体学习情况

## 3. 技术方案

纯前端单页应用（SPA），使用 HTML + CSS + 原生 JavaScript。数据存储在浏览器 localStorage 中，无需后端服务。

### 3.1 技术选型理由

- **零部署成本**：打开 HTML 文件即可使用
- **隐私安全**：所有数据保存在本地浏览器
- **离线可用**：无需网络连接
- **开发快速**：可以快速迭代和验证

## 4. 核心功能

### 4.1 模式切换

顶部导航栏提供模式切换：
- 小孩模式（默认）
- 家长模式

### 4.2 小孩模式

#### 4.2.1 首页/今日任务

- 显示当前日期
- 倒计时提示：「距离开学还有 XX 天」
- 今日任务列表，每条任务包含：
  - 复选框（标记完成/未完成）
  - 任务标题
  - 科目标签（语文/数学/英语，不同颜色区分）
  - 任务类型标签（练习题/背单词/背课文）
  - 预计用时（可选）
- 「添加任务」按钮

#### 4.2.2 添加任务

弹窗表单，字段包括：
- 任务标题（必填，文本输入）
- 科目（必填，单选：语文/数学/英语）
- 任务类型（必填，单选：练习题/背单词/背课文）
- 预计用时（可选，分钟数）
- 日期（默认今天，可选择）

#### 4.2.3 完成反馈

- 勾选完成时有轻微动画效果
- 今日全部任务完成后显示庆祝提示
- 显示连续打卡天数

### 4.3 家长模式

#### 4.3.1 统计看板

- 总完成率（已完成任务数 / 总任务数）
- 连续打卡天数
- 今日完成率
- 各科任务量对比（简单柱状图或数字卡片）
- 最近 7 天完成情况

#### 4.3.2 历史记录

- 按日期倒序展示
- 每天展示任务列表和完成状态
- 可快速跳转查看某天的详情

#### 4.3.3 任务模板管理

- 预设常用任务模板（如「背 20 个英语单词」「做一篇语文阅读」）
- 小孩添加任务时可快速选择模板
- 支持家长添加、编辑、删除模板

## 5. 数据模型

### 5.1 任务 (Task)

```json
{
  "id": "uuid",
  "title": "任务标题",
  "subject": "chinese|math|english",
  "type": "exercise|vocabulary|recitation",
  "duration": 30,
  "date": "2026-07-26",
  "completed": false,
  "completedAt": null,
  "createdAt": "2026-07-26T08:00:00.000Z"
}
```

### 5.2 任务模板 (TaskTemplate)

```json
{
  "id": "uuid",
  "title": "背 20 个英语单词",
  "subject": "english",
  "type": "vocabulary",
  "duration": 15
}
```

### 5.3 设置 (Settings)

```json
{
  "examDate": "2026-09-01",
  "mode": "kid|parent"
}
```

## 6. 视觉设计

- **整体风格**：简洁明亮，适合小学生使用
- **配色**：
  - 语文：红色系
  - 数学：蓝色系
  - 英语：绿色系
- **字体**：清晰易读，字号适中
- **交互**：按钮大，操作简单，减少复杂操作

## 7. 页面结构

```
┌─────────────────────────────────────┐
│  Logo/标题     [小孩模式|家长模式]  │  ← 顶部导航
├─────────────────────────────────────┤
│                                     │
│           主要内容区                 │
│  (根据模式显示不同内容)              │
│                                     │
└─────────────────────────────────────┘
```

## 8. 开发计划

1. 搭建基础 HTML 结构和样式
2. 实现数据存储层（localStorage 封装）
3. 实现小孩模式：今日任务列表、添加任务、完成打卡
4. 实现家长模式：统计看板、历史记录、任务模板管理
5. 添加倒计时功能和视觉优化
6. 测试和调试
